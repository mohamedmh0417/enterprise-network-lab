# Enterprise Network Lab

## Project Overview

This repository documents a hands-on enterprise networking lab focused on building, configuring, testing, and troubleshooting a multi-VLAN network environment.

The goal is to develop practical networking skills through network design, configuration, verification, and technical documentation.

## Lab Objectives

- Design an enterprise-style network topology.
- Configure VLANs and trunk links.
- Implement inter-VLAN routing.
- Configure OSPF dynamic routing.
- Implement DHCP services.
- Explore network redundancy using HSRP.
- Configure STP and EtherChannel (LACP).
- Perform connectivity testing and troubleshooting.
- Document configurations, commands, and test results.

## Technologies

- Cisco IOS networking concepts
- VLANs and 802.1Q trunking
- OSPF
- HSRP
- STP
- LACP / EtherChannel
- DHCP
- Wireshark
- Linux networking tools
